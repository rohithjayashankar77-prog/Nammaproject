## Project Overview
This repository contains a manual testing project completed as part of
classroom training to gain hands-on experience in software testing.
The project was performed on a demo web application under instructor guidance.

## Application Under Test
- Application Type: Demo Web Application
- Purpose: Practice manual testing concepts
- Modules Tested:
  - Login functionality
  - Form validations
  - Navigation flow
  - UI elements

## Testing Activities Performed
- Understanding requirements of the demo application
- Writing test scenarios and test cases
- Executing functional test cases
- Identifying and documenting defects
- Assigning severity and priority to bugs

## Types of Testing
- Smoke Testing
- Sanity Testing
- Functional Testing
- UI Testing

## Test Artifacts
The following documents are included in this repository:
- Test Plan
- Test Scenarios
- Test Cases
- Bug Reports
- Screenshots (if applicable)

## Tools Used
- MS Excel / Google Sheets
- GitHub for documentation and version control
- Browser: Chrome

## Learning Outcome
This project helped me gain practical exposure to manual testing,
improve test case writing skills, and understand the defect life cycle.
